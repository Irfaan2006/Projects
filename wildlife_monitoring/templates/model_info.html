Deep Learning Architecture & Performance Analysis

Mathematical formulation, structural innovations, loss functions, and high-accuracy optimization techniques.

1. YOLOv11 Architecture Innovations

YOLOv11 represents the state-of-the-art in single-stage real-time vision backbones. Compared to YOLOv8 and legacy architectures, YOLOv11 introduces optimized C3k2 blocks, enhanced Spatial Pyramid Pooling Fast (SPPF), and a lightened Decoupled Head.

A. C3k2 & Feature Extraction

The C3k2 module optimizes gradient flow using split-and-merge cross-stage connections with variable kernel sizes, enabling deep feature representation without introducing computational latency. This is crucial for detecting camouflaged animals in dense foliage.

B. Loss Functions

YOLOv11 utilizes a composite loss function combining Bounding Box Regression Loss (\(\mathcal{L}_{box}\)), Distribution Focal Loss (\(\mathcal{L}_{dfl}\)), and Classification Loss (\(\mathcal{L}_{cls}\)):

\(\mathcal{L}_{total} = \lambda_{cls} \mathcal{L}_{BCE} + \lambda_{box} \mathcal{L}_{CIoU} + \lambda_{dfl} \mathcal{L}_{DFL}\)
  • CIoU (Complete IoU): penalizes bounding box center distance, aspect ratio mismatch, and scale error.
  • DFL (Distribution Focal Loss): handles bounding box localization ambiguity under partial visual occlusion.

2. DeepSORT Multi-Object Tracking Engine

DeepSORT tracks individual targets across frame losses, camera movements, and temporary occlusions using a combination of motion estimation and visual appearance embeddings.

A. 8D Kalman State Vector

Each track state vector \(\mathbf{x}\) models spatial coordinates and bounding box dynamics:

\(\mathbf{x} = [u, v, \gamma, h, \dot{u}, \dot{v}, \dot{\gamma}, \dot{h}]^T\)

Where \((u, v)\) is box center, \(\gamma = w/h\) is aspect ratio, \(h\) is height, and \(\dot{u}, \dot{v}, \dot{\gamma}, \dot{h}\) are motion velocities.

B. Dual Distance Association Metric

Matching between active tracks and new YOLOv11 detections uses a linear combination of Mahalanobis motion distance \(d^{(1)}\) and ReID Cosine visual feature distance \(d^{(2)}\):

\(d^{(1)}(i, j) = (\mathbf{d}_j - \mathbf{y}_i)^T \mathbf{S}_i^{-1} (\mathbf{d}_j - \mathbf{y}_i)\)

\(d^{(2)}(i, j) = 1 - \mathbf{r}_j^T \mathbf{r}_k^{(i)}\)
